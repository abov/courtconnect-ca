Read these with care

  • The cost column is the agent’s own estimate (ADR 0019 caps spend), not a bill.
  • Outcomes are copied from the log, which is updated by hand or by the next run, so it can lag what GitHub shows.
  • The history is short: the first scorecard row is from 2026-10-13. A steady line means the checks held, not that every fact on the map is right.
