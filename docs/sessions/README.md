# Session notes

Only the automated routines write here (tournament parts, search-interest refresh, refresh run, refresh watchdog): `docs/tournament_run_parts.md` gates each part on the previous part's note, and `ci/check_refresh_diff.py` allows `*-refresh-run.md`. Name: `YYYY-MM-DD-<topic>.md`, 2-3 lines, one new file per run, never edit another run's note. Old cycles' notes can be deleted.
Interactive sessions write no note: put what changed and what is next in the PR description. Priorities live in `docs/status.md` ("Open, in order"; short list in `CLAUDE.md`); older history is in `docs/archive/session_digest.md`.
The digest also condenses what the earlier interactive notes recorded (rules, dead ends, open follow-ups); the originals are in git history.
