# Session notes

One file per Claude session: `YYYY-MM-DD-<topic>.md`, 2-3 lines (what changed, what is next, PR numbers).
Each session writes only its own new file, so parallel sessions and PRs never conflict.
Never edit another session's note. Priorities live in `CLAUDE.md` ("Open, in order"); older history is in `docs/archive/status_history.md`.
