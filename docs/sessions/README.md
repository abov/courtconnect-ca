# Session notes

Only the automated routines write here (tournament parts, search-interest refresh, refresh run, refresh watchdog): `docs/tournament_run_parts.md` gates each part on the previous part's note, and `ci/check_refresh_diff.py` allows `*-refresh-run.md`. Name: `YYYY-MM-DD-<topic>.md`, 2-3 lines, one new file per run, never edit another run's note.
Interactive sessions write no note: put what changed and what is next in the PR description. Priorities live in `CLAUDE.md` ("Open, in order"); older history is in `docs/archive/status_history.md`.
A few older notes stay because docs link to them; the rest are in git history (`git log -- docs/sessions`).
