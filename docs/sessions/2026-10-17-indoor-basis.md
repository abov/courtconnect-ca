# 2026-10-17: indoor is now "unknown" unless something backs it

- `dim_venue.has_indoor` is three-valued: true (a court tagged indoor), false (a court tagged outdoor/covered, none indoor), null = unknown. New `indoor_basis` (`osm_tag`, `manual_seed`, `unknown`; `page_quote` and `footprint` reserved) in `dim_venue` and `mart_venue_finder`. Overture-only places and untagged OSM pitches (`likely_outdoor` is an assumption) are now unknown instead of false; hand-curated rows with a blank/`unknown` setting too. Test `assert_indoor_has_basis` + accepted_values.
- Result: dim_venue had 10,099 venues with `has_indoor` false; now 212 are explicit false (tagged outdoor/covered) and 9,887 are unknown; 187 are true (unchanged). Indoor-true count unchanged (481 venue/sport rows), and the export treats null as not indoor, so `venues.json` and the popup are unchanged (not regenerated: the local rebuild differed from the committed file by 4 named venues, unrelated).
- Not done: `has_outdoor` still defaults to false for places-only venues; app does not show the unknown state; next is the padel geometry classifier, then page quotes / building footprints as new `indoor_basis` values.
