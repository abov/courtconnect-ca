# 2026-10-18 page reader pilot (ADR 0017): free rules engine measured, model run optional

**Changed:** `ingestion/page_reader.py` (fetch public page, robots.txt, 4 s per host, 14-day cache in `data/reader_cache/`, HTML to text, one Claude call, JSON of fixed fields with an exact quote each; code drops any fact whose quote is not verbatim on the page, any unknown sport, any court count not in its quote). `ci/check_page_reader.py` tests that guard rail offline (wired into CI). `.env.example` has `ANTHROPIC_API_KEY`.
**Dry run (no API call), 20 hand-settled `manual_venues` pages:** 16 readable (about 28,500 input tokens in total, so one pilot costs cents), 4 skipped: 3 blocked by robots.txt (Hawthorne x2, Henderson), 1 fetch error (Glendale YMCA badminton). So the reader cannot reach city sites that block bots; those stay hand review (ADR 0017 consequence).
**Not done:** the model run. No `ANTHROPIC_API_KEY` in this environment and ADR 0017 leaves the spend cap and the precision bar (suggested 90%) to the owner. Run: `python ingestion/page_reader.py --pilot 20 --max-pages 16 --max-usd 1 --usd-per-mtok-in <in> --usd-per-mtok-out <out>`; it writes `docs/reader_candidates.csv` (staged, `inferred`, never applied) and `docs/reader_pilot_results.csv` (reader vs seed: agree / conflict / new). Then record precision and the no-quote share here and decide on scaling.

**Free engine added (2026-10-19), no API key and no cost:** `--engine rules` finds sport names/aliases, "<n> ... courts" counts (the sport must be inside the phrase, or written as "Sport: 4 courts") and strict access phrases ("open to the public", "members only"), then runs the same quote check. `python ingestion/page_reader.py --pilot 20 --engine rules`.
**Result on the 16 readable hand-settled pages (43 facts, 0 failed the quote check):** 0 conflicts with the seed; sport agreed on 13 of 16, court count on 5 of 16, access on 1 of 15 (the rest are "not found", never wrong). So the rules are high precision and low recall: they confirm what a page plainly says and miss anything phrased differently. Two earlier wrong answers (Stanford squash "3" taken from "three basketball courts"; "public courts" in a sentence about other courts) were fixed by tightening the rules, so these numbers are tuned on the same 16 pages and likely a bit optimistic. 24 more facts were "new" (not in the seed, e.g. Round Hill pickleball 4, Alta Vista tennis 7): leads for a person to check, not applied.
**Next, optional:** the Claude engine (needs a key + cap) only if the rules' recall proves too low on a fresh sample of pages; a local open model would be the free middle path (same `verify()`). Pages that block bots (3 of 20) stay hand review either way.
